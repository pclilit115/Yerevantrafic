# Տաքսու լիցենզիաների ռեեստր (նախատիպ)

Ավտոբուսային գծերով երթևեկելու թույլտվության լիցենզիաների ռեեստրի նախատիպ (նախագիծ Շ2)։

- **admin / admin** (ԵԵԿ): տրամադրում է լիցենզիա, ավտոմատ համար և QR կոդ, չեղարկում է՝ պատճառը նշելով, վերականգնում է։
- **user / 112** (Պարեկային ծառայություն): միայն ստուգում է լիցենզիան՝ հերթական համարով կամ QR կոդով։
- QR կոդը բացում է `…/licenses/#lic-0001` հասցեն․ մուտքից հետո տվյալները բացվում են անմիջապես։
- Ժամկետը լրանալուն պես լիցենզիան չեղարկվում է ավտոմատ։

## Կարևոր սահմանափակումներ

- **Տվյալները պահվում են միայն տվյալ բրաուզերում** (localStorage)։ GitHub Pages-ում ընդհանուր բազա չկա, ուստի ադմինի տրամադրած լիցենզիան պարեկայինի հեռախոսում չի երևա։ Իրական աշխատանքի համար անհրաժեշտ է սերվեր և բազա (օր.՝ Supabase կամ Firebase)։
- **Գաղտնաբառերը գրված են էջի կոդում** և տեսանելի են բոլորին։ Դրանք ընդամենը բաժանում են ինտերֆեյսը, պաշտպանություն չեն ապահովում։ Իրական կիրառման համար անհրաժեշտ է սերվերային մուտք։
- QR կոդի հասցեն փոխելու համար խմբագրեք `index.html`-ում `const SITE=` տողը։
- Լոգոների համար ստեղծված են անտեսանելի տեղեր (`logo-left.png`, `logo-right.png`)․ տե՛ս կոդի մեկնաբանությունը։
